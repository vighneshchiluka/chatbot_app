# 🤖 Chatbot App

A real-time one-to-one chat application built using Node.js, WebSockets, PHP, MySQL, HTML, CSS, and JavaScript. The application enables instant messaging, file sharing, online user tracking, and a responsive user experience.

## ✨ Features

* 💬 Real-time messaging using WebSockets
* 🟢 Online / Offline user status tracking
* 📎 File upload and sharing
* ⌨️ Enter key message sending
* 🎨 Smooth and responsive chat interface
* 🔄 Auto-scroll for new messages
* ⚡ Instant message delivery
* 📱 Mobile-friendly responsive design

## 🛠️ Tech Stack

### Frontend

* 🌐 HTML5
* 🎨 CSS3
* ⚡ JavaScript

### Backend

* 🐘 PHP
* 🗄️ MySQL

### Real-Time Server

* 🟢 Node.js
* 🔌 WebSockets (ws)

## 📂 Modules

* 💬 Chat Interface

* 🔄 Real-Time Communication Server

## 🚀 Run Project

### 1️⃣ Start Services

Start Apache and MySQL from XAMPP.

### 2️⃣ Import Database

Import the provided MySQL database.

### 3️⃣ Start WebSocket Server

```bash
node server.js
```

### 4️⃣ Open Application

User 1:

```text
http://localhost/chatbot_project/frontend/?user=1&to=2
```

User 2:

```text
http://localhost/chatbot_project/frontend/?user=2&to=1
```

Real-time chat works instantly without page refresh.
