Chatbot App 🚀

A realtime one-to-one chat application built using Node.js WebSocket, PHP, MySQL, HTML, CSS, and JavaScript.

✨ Features

* Realtime messaging using WebSocket
* Online / Offline user status
* File upload & sharing
* Enter key message send
* Smooth animated chat UI
* Auto scroll messages
* Instant message delivery
* Simple and responsive design

🛠 Tech Stack

* Frontend: HTML, CSS, JavaScript
* Backend: PHP, MySQL
* Realtime Server: Node.js + ws

📂 Modules

* WebSocket realtime server
* Chat UI
* Message storage
* File uploads
* Online user tracking

🚀 Run Project

1. Start XAMPP Apache & MySQL
2. Import database
3. Run Node server

```bash
node server.js
```

4. Open in browser

```bash
http://localhost/chatbot_project/frontend/?user=1&to=2
```

Open another browser/tab:

```bash
http://localhost/chatbot_project/frontend/?user=2&to=1
```

Realtime chat between users works instantly without page refresh.
